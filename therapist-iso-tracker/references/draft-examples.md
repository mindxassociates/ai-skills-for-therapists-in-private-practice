# Draft Examples — Tone and Shape

Drafts are 2 to 4 sentences, lead with the recommendation, carry no greeting or sign-off, and live in their own code block so the user can copy them in one tap. Caveats go outside the code block, for the user only.

## Good drafts

Post asks for a virtual therapist in Texas for anxiety and grief, in network with BCBS:

```
I'd recommend Jane Lee, LCSW for this — she works with anxiety and grief, is licensed in Texas and in network with BCBS, and sees clients virtually. Her profile is here: https://example.com/jane-lee
```

Post asks for a couples therapist in Florida who does Emotionally Focused Therapy:

```
Sharing a suggestion: Mark Ortiz, LMFT does couples work in Florida and uses EFT with couples. He is accepting new clients at the moment: https://example.com/mark-ortiz
```

Post is written in a second language your profile documents, and asks for a therapist who speaks it:

Reply in that language, with the same shape — name, one or two plain reasons tied to the post, state fit, profile link in that language if you have one. Mention the language because the post asked for it. Keep the same no-hype tone.

## Bad drafts (do not ship these shapes)

Too salesy — hype, superlatives, and a specialty list:

```
Hi there! Jane Lee is an excellent, highly experienced therapist and a perfect fit for this client! She specializes in anxiety, depression, trauma, grief, relationships, self-esteem, life transitions and so much more. Don't hesitate to reach out!!
```

Claims more than the profile documents — the post wanted ERP and the profile documents CBT-based OCD work with no dedicated ERP training:

```
Jane Lee is an OCD specialist trained in ERP and would be great for this.
```

Correct handling: either skip, or draft without the claim and flag the gap to the user outside the code block ("Her OCD work is documented as CBT-based, not dedicated ERP, so the draft does not mention OCD treatment specifically — post only if you are comfortable being named on this thread").

Works around a filter — the post's budget is $50 and the provider's sliding scale minimum is $80:

```
Jane Lee offers sliding scale and may be able to work with the budget.
```

Correct handling: exclude that provider for that post. Below a known minimum there is no draft.

Wrong link — a scheduling link instead of a profile link:

```
You can book Jane here: https://calendly.example.com/jane-intro-call
```

Correct handling: profile or website URL only. The reader of a referral thread wants to see who the therapist is, not book on the spot.

## Opener rotation

Rotate openers so consecutive drafts do not read like a template:

- "I'd recommend [Name] for this — ..."
- "[Name] comes to mind for this — ..."
- "Sharing a suggestion: [Name] ..."
- "[Name] could be a good option here — ..." (use "could" only when the fit is real but the post leaves one ordinary detail open; never to hedge an undocumented specialty)
