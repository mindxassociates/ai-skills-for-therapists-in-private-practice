# Starter prompt — copy, paste, send to your AI agent

Upload (or install) every file in this kit first, then paste:

---

Build a practice-coordinator chatbot for my therapy practice using the Practice Chatbot Kit in this workspace.

Follow the kit exactly:

1. Run the **setup interview** in `SKILL.md` first — practice shape and per-language practice names, bot name and title, languages and per-language provider naming, roster source of truth, booking link(s) and free-consultation exceptions, published-fee policy and billing contact, crisis resources, and the platform the chatbot will run on. Do not write the persona until I have answered. Never invent a provider, license, panel, fee, link, or exception — use placeholders and flag every one.
2. Build the **roster** from my source of truth: one entry per clinician with license states, client types, age groups, specialties, languages, published panels, accepting status, and exceptions — including any geographic exclusion, which is recorded but never volunteered.
3. Fill in `references/persona-and-instructions.md` completely. Search the finished file for a leftover `[` before calling it done. Confirm the matching order with me: license state first, then specialty, panel, language, and age group.
4. Obey the kit's hard rules: booking links are copied character-for-character, never constructed; fees are quoted only if published and only when cost is asked about; billing and insurance questions route to my billing contact with no copay, deductible, or benefit estimates; a crisis disclosure gets my configured crisis resources immediately, in the visitor's language, with no assessment, no counseling, and no booking in that moment; the chatbot never makes compliance claims.
5. Test before I go live: in-scope match, out-of-state visitor, age-group mismatch, no-fit specialty, fee question, billing question, and crisis disclosure — each in every language the chatbot serves, in a fresh session per case. Fix the persona, not the test, when a case fails, and show me the results case by case.
