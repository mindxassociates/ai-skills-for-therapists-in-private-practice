# Starter prompt — copy, paste, send to your AI agent

Upload (or install) every file in this kit first, then paste:

---

Set up Snoooz.ai email automation for my therapy practice using the Snoooz Inbox Automation Kit in this workspace.

Follow the kit exactly:

1. Run the **setup interview** first: open `config.md` and ask me every CONFIRM field in small groups — practice identity and inboxes, booking links and free-consultation offer, panels and rates confirmed for *this* practice, EAPs, optional rules, and the draft-first period. Fill `references/provider-profile.md` from my answers and read the corrections back to me. Never carry over a panel, rate, link, or contact from another practice I work with unless I confirm it for this one.
2. Build the foundations before any rule: the Gmail labels and Snoooz categories in `references/rule-recipes.md`, plus Data Sources for my website, directory profiles, and rates/FAQ page — and check each imported source once.
3. Build in kit order: the five **exclusion rules first**, then Psychology Today (one rule per language I serve), Directories, my confirmed EAP rules, Existing Clients, Billing, and General Inquiries last as the catch-all. Paste prompts from `references/rule-recipes.md`, replace every bracket from `config.md`, and search each finished prompt for a leftover `[` before saving.
4. Obey the kit's hard rules: the seven gates (age, client type, insurance, location, crisis, format, fees) go on every prospective-client reply in order; hard gates decline warmly with no booking link; insurance answers come only from my confirmed panel list with no copay, deductible, or benefit estimates; a crisis mention opens with 988 and 911 (US) and no counseling; availability-style EAP requests stay Draft permanently; the Google Voice and vacation rules stay off unless I say yes to each one separately, after the warnings.
5. Test with **no-send simulations** before anything goes live — the full battery in `references/setup-checklist.md`, in each language each rule serves. Fix the prompt, not the test, when a case fails.
6. Go live in stages: exclusions on, reply rules in Draft for my review period, then Send one rule at a time only on my explicit go-ahead. **Reopen every saved rule** and verify prompt, action, label, schedule, and Reply to Lead's Email against the recipe — a save that was never reopened does not count as done.
7. Hand me a plain inventory: each rule by name, order, action, label, and live/draft status; the simulation results case by case; and anything not built, with the reason.
