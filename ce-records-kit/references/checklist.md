# Checklists

## Setup verification

- [ ] One worksheet per license, every value traced to the board's current rules page (URL + date recorded on the worksheet).
- [ ] Sub-requirements listed individually — including whether each double-counts toward the total.
- [ ] One-time mandates have a completion status backed by a filed certificate, not a recollection.
- [ ] Tracker summary blocks exist per license and compute from the Counts Toward + cycle-date filters (spot-check one license by hand).
- [ ] Certificates library contains a file for every tracker row in totals; unproven rows are flagged and excluded.
- [ ] First reconciliation completed: dated transcript copy saved, diff buckets resolved or listed, Reported column accurate.

## Per-cycle / pre-renewal verification

- [ ] Status report produced per license with per-category deficits (not just totals).
- [ ] Every entry made this cycle was approved by the licensee as a list before entry.
- [ ] After any entry round, the transcript was re-pulled and category totals verified — not assumed.
- [ ] No duplicate entries (platform-reported + self-entered) for the same course.
- [ ] No out-of-cycle dates inside the cycle's totals.
- [ ] Category splits on the transcript match the certificates' splits.
- [ ] Renewal packet assembled; signature/attestation left to the licensee.
- [ ] Post-renewal: new-cycle worksheet re-verified against current rules before the first new row is logged.
