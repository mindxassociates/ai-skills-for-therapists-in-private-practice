# Setup and maintenance

## First-time setup, in order

1. **Worksheets first** — one per license, verified from current board rules (`requirements-and-categories.md`). Licensee confirms them; they are the system's constitution.
2. **Tracker** — build the spreadsheet with the schema and per-license summary blocks (`tracker-and-certificates.md`).
3. **Certificates harvest** — gather what already exists for the current cycle: download folders, email receipts, provider dashboards (large CE platforms keep a transcript of their own — export it), any existing tracker or notes the licensee keeps. File everything into the library, then build tracker rows **from the certificates**.
4. **First reconciliation** — expect the official transcript and the tracker to disagree on day one; that's the kit working, not failing. Run the full routine (`reporting-system-reconciliation.md`) so the cycle starts clean.
5. **Set the rhythm** — put the periodic status and the pre-renewal reconciliation on the calendar (or as recurring agent tasks): quarterly status, monthly in the cycle's final quarter, reconciliation at mid-cycle and at T-60 days before the renewal deadline.

## The periodic status (what the licensee sees)

Per license, one block:

```
<Board — License Type> · cycle ends <date> · renewal deadline <date>
Total:        banked X.X / required Y  (deficit Z.Z or ✓)
Ethics:       banked X.X / required Y  (…)
Supervision:  banked X.X / required Y  (…)
<each named sub-requirement, same shape>
One-time mandates: all complete ✓ / <name> outstanding
On transcript: verified <date> / entries pending: N
Next action: <the cheapest course that closes the biggest deficit, noting multi-license credit>
```

The "next action" line is the point of the report: given the deficits and the Counts Toward column, name the enrollment that closes the most gap — ideally one course that counts toward two licenses and carries the missing category.

## Renewal packet (T-60 to deadline)

- [ ] Final reconciliation done; transcript totals verify complete per category, per license.
- [ ] Dated transcript copy saved with the cycle records.
- [ ] One-time-mandate certificates located and in the packet.
- [ ] Renewal fee + method noted; renewal form prepared.
- [ ] **Handed to the licensee at the signature line.** The agent prepares; the licensee attests, signs, submits, and keeps the confirmation.
- [ ] After renewal: open the next cycle — new worksheet verification (rules may have changed), new summary blocks, certificates folder for the new cycle, rhythm re-set. Courses already taken that fall in the new cycle are its first rows.
