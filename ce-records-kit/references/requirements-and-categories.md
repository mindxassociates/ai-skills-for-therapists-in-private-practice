# Requirements worksheet — one per license

Complete one worksheet per license held. Every value is verified against the board's **current published rules** at setup and again at the start of each new cycle; record the source URL and the date verified next to the worksheet, so the next check knows what "current" meant.

## Worksheet fields

| Field | Notes |
|---|---|
| Licensee name (as licensed) | Exactly as the board has it — reporting systems match on it. |
| Board / licensing authority | Full name + the rules page URL. |
| License type + number | Private record; keep the worksheet with the clinician's own files, not in anything shared. |
| Cycle start / cycle end | The CE cycle dates, from the board — not inferred from the license print. |
| Renewal deadline | May differ from cycle end (grace, late windows, hard stops). Record what happens after it. |
| Total hours required | Per cycle. |
| Ethics hours | Minimum, and whether ethics hours also count toward the total (usually yes — verify). |
| Supervision hours | If the licensee holds/maintains a supervisor credential: minimum + any approved-supervisor-specific rules. |
| Other named sub-requirements | Cultural competence, telehealth, specific-topic mandates — each with its minimum and whether it double-counts toward the total and/or another category. |
| One-time mandates | Topic, required by when, completed (date + certificate location), and the board's evidence that it's truly one-time vs. per-cycle. |
| Method / delivery rules | Live vs. recorded/home-study caps; synchronous requirements; any per-course hour caps. |
| Provider approval rules | Must providers be board-approved? Are national platforms / professional-association providers accepted? Out-of-state board approvals honored? |
| Reporting system | Name (e.g. CE Broker), URL, how the official transcript is obtained, whether entry is by the licensee, the provider, or both. |
| Audit window | How many years certificates must be retained after renewal. |
| Verified on | Date + rules-page URL for this verification round. |

## Category rules worth getting right

- **Sub-category hours usually also count toward the total** — but "usually" is doing work in that sentence. Verify per board, per category, and record the answer; the tracker's math depends on it.
- **A course can carry multiple category tags** (a supervision course that is also an ethics course). The certificate's own breakdown governs: if the certificate grants 1.75 total with 1.75 ethics and 1.75 supervision, the tracker records exactly that — never round, never infer a split the certificate doesn't state.
- **Multi-license counting:** the same course may satisfy several licenses' requirements when each board accepts the provider and method. Record per-course, per-license applicability as a checked field (see the tracker schema) — it's the highest-leverage column in the system, because one well-chosen course can close gaps in two states at once.
- **First-cycle / newly-licensed proration** and **inactive/reactivation rules** exist in many states. If either applies to the licensee, it gets its own worksheet line — do not apply the standard numbers.
